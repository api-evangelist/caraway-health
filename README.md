# Caraway Health *

Caraway Health is a digital health company that provides virtual mental and physical healthcare designed for college and university students, delivered through a mobile app with support offered around the clock. It partners with higher-education institutions and is backed by GV (Google Ventures). It operates as a direct-to-consumer / campus telehealth provider rather than an API platform; no public developer program or API specification was found during enrichment. Sector: life-sciences / digital health.

Backed by: gv — https://caraway.health
